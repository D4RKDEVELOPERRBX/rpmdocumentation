Introduction

Everything a scripter needs to write, insert, and reference code inside RoleplayM's sandboxed script editor. Every function and service below ships with a runnable example.

How does this work? Certain Roblox services are disabled inside the sandboxed script editor for security reasons. OTM Engine provides custom functions, events, and services as workarounds — giving you similar functionality without exposing user data or core OTM systems to arbitrary scripts.
How do I insert a script? Right-click the target object in the Explorer, then search the Insert menu: Script for a server script, or Local Script / Module Script for their respective types.
Maintaining this page Everything below is rendered from a single DATA table at the top of the page's script. To add or edit a service, function, or event, edit that table — no markup required.

Restricted Items

Prevented functions, events, and services during script development. Their OTM-prefixed counterparts (e.g. OTM:DataStoreService) are the sandbox-safe replacements.

Custom Services

Every service is fetched through the otm root object, then called like any Roblox service.

Custom Functions

Global functions available directly in any script — no GetService call needed.

Custom Events

Global events, connected the same way as any Roblox signal.

Custom Events — Add-ons

Add-on events are reached through OTM:AddonService, not the global namespace.

Plugin Creation

Build custom plugins that extend the OTM Engine itself.
