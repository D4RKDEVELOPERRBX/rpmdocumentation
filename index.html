OTM Engine Script Reference

Authored by @d4rkdeveloper · OTM Studios / RoleplayM

Introduction

Everything a scripter needs to write, insert, and reference code inside RoleplayM's sandboxed script editor. Every function and service below ships with a runnable example.

How does this work? Certain Roblox services are disabled inside the sandboxed script editor for security reasons. OTM Engine provides custom functions, events, and services as workarounds — giving you similar functionality without exposing user data or core OTM systems to arbitrary scripts.
How do I insert a script? Right-click the target object in the Explorer, then search the Insert menu: Script for a server script, or Local Script / Module Script for their respective types.

Custom Services

Every service is fetched through the otm root object, then called like any Roblox service.

OTM

Root engine service — the entry point for retrieving every other service.

GetService(serviceName)Table
ParameterTypeDescription
serviceNameStringReturns the requested service.
GetServices()Table

Lists all current services.

FindService(serviceName)Table | nil
ParameterTypeDescription
serviceNameStringSame as GetService, but returns nil instead of erroring if it doesn't exist.
Example
local dss = otm:GetService(ServiceName) -- gets the requested service
local allServices = otm:GetServices() -- gets all existing services
local serviceExists = otm:FindService(ServiceName) -- nil if it doesn't exist

OTM:DataStoreService

The sandbox-safe replacement for Roblox's DataStoreService.

GetDataStore(name)Datastore
ParameterTypeDescription
nameStringReturns the datastore named SERVERNAME_YOURNAME.
Example
local dss = otm:GetService("OTM:DataStoreService")
local mainStore = dss:GetDataStore("mainStore")

game.Players.PlayerAdded:Connect(function(plr)
    mainStore:SetAsync(plr.UserId, true) -- true when the player joins
end)

game.Players.PlayerRemoving:Connect(function(plr)
    mainStore:SetAsync(plr.UserId, false) -- false when the player leaves
end)

OTM:EngineService

The engine's main core service — session and load-state info.

InMapEditor()Bool

Returns whether the current session is in the map editor.

IsServerLoaded()Bool

Returns whether the server has fully finished loading.

WebhookEnabled()Bool

Returns whether a webhook has been set up on the server.

Example
local engine = otm:GetService("OTM:EngineService")

if engine:InMapEditor() then
    return -- skip gameplay logic while in the map editor
end

if engine:IsServerLoaded() and engine:WebhookEnabled() then
    print("Server ready, webhook logging is active.")
end

OTM:MarketplaceService

Prompts and asset-ownership checks, mirroring Roblox's MarketplaceService.

PromptGamepass(player, gamepassId)None

Prompts the given Roblox gamepass to the user.

PromptProduct(player, productId)None

Prompts the given Roblox developer product to the user.

UserOwnsAsset(player, assetId)Bool

Checks whether the Roblox user owns the given asset.

ImportPaidContent(rpmId)None WIP

Inserts a paid RPM asset via a custom ID.

GetPaidContentInfo(rpmId)Table WIP

Returns info for a paid RPM asset via its custom ID.

UserOwnsPaidContent(player, rpmId)Bool WIP

Returns whether the asset is owned.

Example
local mps = otm:GetService("OTM:MarketPlaceService")
local player = game.Players.Unknownblocky
local gamepassId = 0
local productId = 0
local rpmId = 0
local assetId = 0

local ownsAsset = mps:UserOwnsPaidContent(player, rpmId)

mps:PromptGamepass(player, gamepassId)
mps:PromptProduct(player, productId)

if ownsAsset then
    local asset = mps:ImportPaidContent(rpmId)
    local assetInfo = mps:GetPaidContentInfo(rpmId)
    local ownsAssetV2 = mps:UserOwnsAsset(player, assetId)
    print(asset)
    print(assetInfo)
end

OTM:ModerationService

Bans, unbans, and admin/moderation history.

BanAsync(banner, userId, duration, reason)None

Bans the given user.

UnbanAsync(userId)None

Unbans the given user.

ModerationHistory(userId)Table

Returns the user's moderation history.

IsAdmin(player)String | nil

Returns the user's admin rank, or nil if none.

UserBannedAsync(userId)Bool

Returns whether the user is currently banned.

OnUserBan(userId, duration, reason)WIP

Event — fires with a user's ban details.

Example
local modService = otm:GetService("OTM:ModerationService")
local plr = game.Players.Unknownblocky
local userId = plr.UserId
local banDuration = 3600 -- 1 hour, in seconds
local banReason = "OTM STUDIOS"

local isAdmin = modService:IsAdmin(plr)
print(isAdmin) -- e.g. "OTM Staff"

modService:BanAsync(plr, userId, banDuration, banReason)
modService:UnbanAsync(userId)
modService:ModerationHistory(userId)
modService:UserBannedAsync(userId)

modService.OnUserBan:Connect(function(bannedUserId, duration, reason)
    local username = game.Players:GetNameFromUserId(bannedUserId)
    print(username .. " was banned for:", duration, "Reason:", reason)
end)

OTM:AddonService

Connects your script to installed paid add-ons.

GetAddon(name)Table

Imports the given add-on's functions/events into your script.

AddonEnabled(name)Bool

Checks if the server currently has the add-on enabled — useful for checking whether it's running or owned.

GetAddonInfo(name)Table WIP

Returns info about the given add-on.

RestartAddon(name)None WIP Owner-only

Restarts the given add-on. Errors if you don't own it.

StopAddon(name)None WIP Owner-only

Stops the given add-on. Errors if you don't own it.

StartAddon(name)None WIP Owner-only

Starts the given add-on. Errors if you don't own it.

Example
local addonService = otm:GetService("OTM:AddonService")
local currentAddon = "test_addon"

local testAddon = addonService:GetAddon(currentAddon)
local addonEnabled = addonService:AddonEnabled(currentAddon)
local addonInfo = addonService:GetAddonInfo(currentAddon)

print(addonEnabled) -- true/false: enabled (owned)
print(addonInfo) -- {Creator = "D4RK", Price = 0, Description = "Hello world!"}

if addonEnabled then
    addonService:StopAddon(currentAddon)
end

addonService:StartAddon(currentAddon)
addonService:RestartAddon(currentAddon)

testAddon.Changed:Connect(function(arg1) -- add-ons expose their own functions/events
    print(arg1)
end)

OTM:StarterPack

Manages what players spawn with.

AddItem(toolName, amount)None

Adds the tool to the game's StarterPack.

RemoveItem(toolName)None

Removes the tool from the StarterPack.

FindItem(toolName)Bool

Checks whether the item exists in the StarterPack.

AddOneTimeItem(toolName, amount)None

Gives the item to a character only once per player. Passing "cash"/"bank" with an amount grants cash instead.

RemoveOneTimeItem(toolName)None

Removes the item from the one-time list.

FindOneTimeItem(toolName)Bool

Checks whether the item exists in the one-time list.

Example
local starterPack = otm:GetService("OTM:StarterPack")
local item = game.ReplicatedStorage["g17"]

local foundItem = starterPack:FindItem(item)

if foundItem == false then
    starterPack:AddItem(item, 30) -- spawns with a G17, 30 rounds
    starterPack:AddOneTimeItem(item, 30) -- only given once per player
end

OnBulletShot

In progress

Fires when a bullet is shot in the world.

OnBulletShot:Connect(function(player, tool, hit))
Example
local whitelistedDevs = {"Unknownblocky", "Zeolah"}
local blacklistedTools = {"Taser"}

OnBulletShot:Connect(function(player, tool, hit)
    if hit == nil then return end
    if table.find(blacklistedTools, tool.Name) then return end

    if table.find(whitelistedDevs, player.Name) then
        Explode(hit, 25, 30, 150) -- exploding bullets for devs
    end
end)

Plugin Creation

Build custom plugins that extend the OTM Engine itself.

Plugin API

Methods available on the api argument passed into a plugin's Init(self, api).

RegisterService(name, impl)None

Registers a table as an OTM service, callable via otm:GetService(name).

RegisterFunction(name, func)None

Adds a global function available inside every executed script.

RegisterEvent(name, existingEvent)OTMEvent

Creates (or wraps) a named event, retrievable via otm:GetEvent(name).

GetEvent(name)OTMEvent | nil

Returns a previously registered event, or nil.

OnBeforeExecute(fn)None

Registers a hook that fires right before every user execution, receiving the player and their code.

OnAfterExecute(fn)None

Registers a hook that fires right after every execution, receiving the player, success, elapsed time, and error.

Log(msg)None

Prints a message tagged with the plugin's name.

Warn(msg)None

Warns a message tagged with the plugin's name.

Event Object

Returned by api:RegisterEvent, otm:CreateEvent, and otmEvent.new — the same event type used throughout the engine.

Connect(callback)Connection

Runs the callback every time the event fires.

Once(callback)Connection

Runs the callback the next time the event fires, then disconnects itself.

Wait()...

Yields the current thread until the event fires, then returns its arguments.

Fire(...)None

Fires the event, running every connected callback with the given arguments.

DisconnectAll()None

Disconnects every listener on the event.

GetConnectionCount()Number

Returns how many listeners are currently connected.

Full plugin example

A minimal plugin registering a service, a global function, lifecycle hooks, and a log line.

return {
    Name = "MyPlugin",
    Version = "1.0",

    Init = function(self, api)
        api:RegisterService("CoolService", {
            DoThing = function(x) return x * 2 end,
        })

        api:RegisterFunction("shout", function(msg)
            print(string.upper(msg))
        end)

        api:Log("Ready")

        api:OnBeforeExecute(function(plr, code)
            -- fires before every user execution
        end)

        api:OnAfterExecute(function(plr, success, elapsed, err)
            -- fires after every execution
        end)
    end,
}
